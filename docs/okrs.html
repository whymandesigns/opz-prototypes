OKR basics

An Objective is a qualitative, inspiring goal — the "what" you want to achieve. Key Results are the quantitative metrics that define whether you've achieved it — the "how you'll know."

PartTypeExample
Objective Qualitative Expand into EMEA markets
Key Result Quantitative Launch in 3 new EU countries by Sep 30
Key Result Quantitative Achieve ISO 27001 certification
Key Result Quantitative Sign 5 enterprise contracts in EU
OKRs are managed separately OKRs are created and managed in the OKRs section of Operationalize — not inside the initiative form. When creating an initiative, you link to OKRs that already exist. This design keeps OKRs as the source of truth and allows multiple initiatives to contribute to the same objective.

Linking OKRs to an Initiative

An Initiative can be linked to one or more Objectives. It's common for a large initiative to contribute to multiple Objectives — for example, a platform migration might advance both a performance OKR and a reliability OKR.

1
Open the OKRs tab
Inside the initiative form, navigate to the "OKRs" section. You'll see OKRs grouped by quarter and team.
2
Find the Objective
Search by objective name or browse by team. You can link at the Objective level — all Key Results under it are automatically included.
3
Update Key Result progress
Once linked, Key Result progress is editable directly from the initiative. Updates sync back to the OKR record — no need to update in two places.

Progress tracking

Key Result progress is shown as a progress bar in the initiative view and feeds into ROB meeting agendas. Progress is calculated differently based on Key Result type:

KR TypeHow progress is calculated
Numeric Current value ÷ target value. E.g. 2 countries launched out of 3 target = 66%.
Percentage Manually entered as a percentage (0–100%). Used for milestones like certification where the path is non-linear.
Boolean Done / Not done. Shows 0% or 100%. Good for binary deliverables.
Update KRs weekly, not just at quarter-end Progress visibility is only useful if it's current. Teams that update Key Results weekly catch problems early. Teams that update at quarter-end use OKRs as a reporting exercise rather than a management tool.

Writing good Key Results

A Key Result should be measurable, time-bound, and ambitious but achievable. Avoid vague language.

Weak KRStrong KR
Improve performance Reduce p95 API latency from 800ms to under 200ms by Aug 31
Get more enterprise customers Sign 5 enterprise contracts ≥ $50K ARR in Q3
Launch in Europe Go live in DE, FR, and NL with localized UI and GDPR-compliant data handling
