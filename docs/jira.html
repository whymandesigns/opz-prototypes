What you can link

Operationalize supports three types of Jira links. Choose based on the granularity of work you want to track:

Jira typeWhen to useWhat's shown
Epic The work for this initiative maps to one or more Jira epics. Most common for product teams. Issue count by status, sprint progress bar, blocked issue count.
Project The initiative spans an entire Jira project (e.g. an infrastructure project that only exists for this initiative). Aggregate issue count, active sprint name, last updated date.
Board You want to track a specific kanban or scrum board regardless of project boundaries. Column distribution of issues, WIP counts.

Connecting Jira

Jira Cloud only Operationalize currently integrates with Jira Cloud (atlassian.net). Jira Data Center / Server support is on the roadmap. If your team uses Jira Server, you can still paste issue URLs as document links in the Documents section.
1
Admin connects Jira Cloud
Go to Admin Settings → Integrations → Jira. Click "Connect Jira Cloud" and authorize via Atlassian OAuth. This links your Atlassian organization — all projects become searchable.
2
Search for epics or projects
In the initiative's Jira section, type the epic name, issue key (e.g. EMEA-421), or project name. Results appear as you type.
3
Select and confirm
Click the item to link it. Progress data syncs every 15 minutes. You'll see a "Last synced" timestamp next to each linked item.

Progress signals

Jira progress data appears in three places across Operationalize:

  • Initiative detail view — live progress bar and issue breakdown
  • ROB meeting agenda — sprint completion % shown next to the initiative name
  • Slack digest — blocked issue count included in the weekly Friday message
Delivery progress ≠ initiative status Jira progress tells you how much work is done. It doesn't automatically update the initiative's status (On Track / At Risk). The owner still sets status manually based on their judgment. A sprint at 90% completion can still be At Risk if the remaining 10% is a critical path blocker.
